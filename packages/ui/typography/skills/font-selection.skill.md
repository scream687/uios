# Font Selection Expert Skill (font-selection.skill.md)

## Objective
Select ultra-curated font pairings based on brand psychology and domain intent.

## Execution Rules
1. For **Luxury / Editorial**: Select high-contrast Serif display (e.g., Playfair Display, Bodoni) paired with clean Sans body (Inter, Neue Haas Grotesk).
2. For **Developer / Dark SaaS**: Select Mono display (JetBrains Mono, SF Mono) paired with Inter body.
3. For **Swiss Minimalist**: Select pure Grotesk (Neue Haas Grotesk, SF Pro Display) for both display and body.
