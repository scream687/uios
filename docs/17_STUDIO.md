# 17_STUDIO: UIOS Studio Workbench Specification

## 1. Overview
UIOS Studio (`apps/studio`) is a web-based orchestration workbench built with Next.js 14 App Router and Tailwind CSS.

## 2. Capabilities
- **Visual Inspector**: Real-time rendering of compiled AST and IR component nodes.
- **Critic Dashboard**: Real-time 8-persona audit score reporting.
- **Live Demo Workbench**: Test pages for EstateLink (`/estatelink`), EstateJoy (`/real-estate-designjoy`), and Aetheris Real Estate SaaS (`/real-estate-saas`).
