# 04_COMPILER_SPEC: UIOS Compiler Specification

## 1. Overview
The UIOS Compiler (`@uios/compiler`) is a deterministic transformation engine.

## 2. Compiler Subsystems
- `ast/`: AST Node schema and hierarchical parser.
- `taste/`: Anti-slop layout rules, HSL palette rationing, and negative headline tracking (`-0.045em`).
- `tie/`: Taste Intelligence Engine with `ComponentGenome` metadata and `TrendEngine`.
- `v2/`: `DesignIR`, 10 LLVM Passes, Design Contracts, and Validation.
