# 22_FILE_FORMATS: UIOS Artifact File Format Specifications

## 1. Supported Schema Artifacts
- `project.spec.json`: Project intent specification.
- `brand.dna.json`: BrandDNA token object.
- `design.ast.json`: Serialized `DesignASTNode` hierarchy.
- `design.ir.json`: Serialized `DesignIRNode` layout representation.
- `critic.report.json`: Audit scores and diagnostics across 8 specialist personas.
- `contracts.json`: Quantitative Design Contract validation state.
- `build.manifest.json`: Emitted code manifest and file tree.
