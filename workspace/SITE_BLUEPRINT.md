## 2. Component Contract Requirements

1. **`HeroSection`**: Heading size `88px`, tracking `-0.045em`, serif italic accent, 3D card tilt hover physics.
2. **`InfiniteMarquees`**: 25s linear duration, opposing horizontal scroll.
3. **`RequestQueueSimulator`**: Interactive input form, list state, status badges (`In Progress`, `Queued`).
4. **`PricingMatrix`**: Monthly ($4,995/mo) / Quarterly ($3,995/mo) toggle, "Pause or cancel anytime" guarantee.
5. **`FAQAccordion`**: `AnimatePresence` height transition, rotating chevron icon.
6. **`BookingModal`**: Backdrop blur, scale-in animation, keyboard focus trapped inside dialog.
